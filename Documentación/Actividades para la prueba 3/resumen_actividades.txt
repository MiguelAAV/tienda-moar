3. Instrucciones generales y contexto 
 
Esta actividad tiene como fin alidad que ejecutes, recolectes resultados y corrijas los defectos encontrados en los Casos de Prueba. 
Con esto también simularemos las Pruebas de Aceptación que efectuaría el cliente para validar el Software. 
 
4. Instrucciones para el/la estudiante  
  
 
La actividad consta de varios procesos en donde tú equipo de trabajo  deberá ejecutar las pruebas de aceptación (AUT) para validar 
que el sistema cumple con los requisitos de aceptación y expectativas del usuario final.  
Para ello, debes confeccionar una versión preliminar de un informe con los resultados obtenidos del proceso. Para lograrlo, debes: 
1. Seleccionar el listado con las (AUT) y los criterios de aceptación de estas. 
2. Ejecutar las pruebas (AUT). 
3. Documentar el proceso registrando los hallazgos obtenidos. 
4. Corregir los defectos encontrados y repetir los pasos 1, 2, 3 y 4 tantas veces como sea necesario. 
5. Elaborar un informe detallando el procedimiento realizado y los resultados obtenidos. 
6. Generar conclusiones preliminares. 
 
Los siguientes artefactos te ayudaran en este proceso y los encontraras en los Recursos de la Actividad en AVA: 
 3.1.3 Planilla listado de defectos 
 3.1.4 Plantilla Informe de Resultados Plan de Pruebas

        Antecedentes generales 
 
Esta actividad tiene como finalidad confeccionar un informe ejecutivo para la alta gerencia, que 
muestre datos del proceso de testing  desarrollado, con la finalidad de presentar métricas que 
permitan evaluar el rendimiento del área de pruebas y tomar decisiones para la mejora continua. 
 
  Requerimientos para esta actividad 
 
 
Para el desarrollo de esta actividad deberás disponer de: 
 
● Computador 
 
Actividad   
 
 
 
La actividad, que debe ser desarrollada por parte de la dupla de  testing, es la confección de un 
reporte ejecutivo en donde deben:  
  
 Recopilar y analizar los datos obtenidos en el proceso de testing, como métricas de defectos, 
tiempos de prueba, y cumplimiento de plazos.  
 Comparar las métricas con los objetivos planteados en el Plan de Pruebas y validar si se 
cumplieron.  
 Utilizar los datos para evaluar el rendimiento del área de pruebas y tomar deci siones 
informadas para la mejora continua.  
 Proponer áreas de mejora para futuros proyectos.  
 Indicar las lecciones aprendidas del proceso realizado.  
 
Instrucciones para el envío de la actividad 
 
El representante del grupo deberá cargar los archivos solicitados, utilizando el siguiente formato 
para el nombre del mismo: NombreApellido_NombreApellido_NombreApellido.RAR vía Mensajes 
(AVA).
